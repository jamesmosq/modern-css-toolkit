# Modern CSS Toolkit Changelog

## [Unreleased]

### Added

- 32 live templates for modern CSS, each labelled with its Baseline status: layout (auto grid, subgrid, container queries, dynamic viewport height, range media queries, scroll snap, logical spacing), selectors (`:has()`, `:where()`, `:focus-visible`, `:nth-child(of)`), architecture (cascade layers, modern reset, component scaffolds with nesting, BEM or `@scope`, `@property`, container style queries), color (OKLCH tokens with `color-mix()`, `light-dark()`, relative colors, dark mode), typography (fluid type, balanced headings), motion (reduced motion, smooth scroll, entry animations, dialog animations, view transitions), accessibility (visually hidden) and forms (`field-sizing`).
- Templates work in CSS, SCSS, Less and `<style>` blocks, and are not offered in the indented Sass syntax (`.sass`), where braces are invalid.
